Bring it into Copilot

Install the canvas.

You need Git, Node.js 22 or newer, your own Copilot access, and a Copilot desktop build that supports custom canvas extensions. Review the source before running the installer.

Full installation and update guide ↗
git clone https://github.com/sviera91/github-certification-coach.git
cd github-certification-coach
node install.mjs

Restart Copilot, open a conversation, and ask:
Open the Certification Coach canvas.

A browser or VS Code Copilot installation alone cannot host the canvas. For updates, run git pull --ff-only, rerun the installer, and restart Copilot.

Humans make this better

Help turn Preview into trusted practice.

AI authorship is a starting point, not a quality seal. We need people who know the subject to challenge the questions and check the evidence. No canvas installation or mock exam is required to review the bank.

Validate the content

Review the certification packets in the repository. Verify one best answer, plausible distractors, explanation consistency, non-revealing hints, blueprint relevance, and current official sources. Check Spanish and Portuguese translations for equivalence.

Open human-review packets ↗

Contribute QA and fixes

Report an incorrect question with its ID and content revision, propose a correction in a pull request, or test timing, navigation, persistence, accessibility, and translations. Human approval is revision-specific; content changes require a fresh review.

Your practice stays yours.

Lite stores learner progress in this browser using IndexedDB. It does not upload answers, scores, or flags to GitHub and does not sync with the desktop canvas. Clearing site data or using private browsing can remove progress. GitHub Pages serves the site and may process normal request metadata; linked study resources and GitHub issue forms have their own policies.

The full canvas stores progress on your computer. Only requested AI coaching is sent through your Copilot conversation. Reports open a public GitHub form for you to review and submit yourself. No analytics or tracking scripts are added by this project.
